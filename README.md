# Multiplayer_Sovereign_Bros
Sovereign Bros is a 2D platform game developed in C++ using the Qt Framework. The project features both single-player and LAN multiplayer gameplay, allowing players to explore interactive levels, battle enemies, collect items, and overcome platforming challenges. Built using Qt's graphics framework and object-oriented programming principles, the game demonstrates collision detection, custom game physics, networking, animations, audio integration, and modular software design. The project was developed to strengthen practical skills in game development, software engineering, and multiplayer programming.
